# مولدتي 10

نسخة عرض تجريبية مستقلة لإدارة المولدات. بيانات وهمية، بدون Firebase أو قاعدة بيانات أو حفظ سحابي أو محلي. جميع التعديلات في ذاكرة الصفحة فقط وتُعاد بيانات العرض عند إعادة التحميل أو المغادرة. يوجد زر لإنهاء التجربة ومسح التعديلات.

لا توجد خدمة عامل (Service Worker) أو تثبيت PWA أو تخزين للتشغيل أوفلاين. قد يحتفظ المتصفح بملفات الموقع الثابتة وفق سياسة GitHub Pages؛ هذا لا يحفظ معاملات المستخدم. لا يمكن ضمان منع نسخ أو تعديل تطبيق عام مفتوح المصدر.

التشغيل: `npm ci` ثم `npm run dev`. الفحص: `npm test` و`npm run lint`. البناء: `npm run build -- --base=/mawldati10-demo/`.
